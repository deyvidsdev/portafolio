# Portafolio de Deyvids

- Astro 6, React 19, TypeScript, Tailwind 4. Usa npm y conserva package-lock.json.
- Mantén el diseño del boceto: marfil, azul, coral, mapa técnico y tipografía original.
- HTML estático para contenido. React solo para interacciones con estado.
- Mantén completas las versiones española e inglesa.
- No inventes clientes, métricas, resultados, certificaciones ni estados de producción.
- No publiques contactos privados, código de clientes o credenciales.
- Los formularios deben enviar realmente o explicar qué hacen. Evita simulaciones de éxito.
- Verifica npm run check, npm run build y la interacción afectada en navegador.
- Revisa móvil, teclado, contraste y reducción de movimiento al cambiar interfaz.
- La publicación del sitio y cambios DNS necesitan un encargo explícito; crear el repositorio no equivale a publicar el sitio.
