# Punto de partida

Fuente: `User dashboard.zip`, exportación de Figma Make del 22/09/2026. El ZIP original permanece en Descargas.

- React 19, Vite y Tailwind 4; configuración Vite acoplada a Figma.
- Paleta: fondo marfil #F6F3EE, azul #1A2744, coral #C8432A; líneas rectas, paneles y mapa técnico ilustrado.
- Fuentes originales Bangers, Lora y JetBrains Mono. Se conservan y se alojan con el sitio.
- Una página, nueve secciones, idioma en estado React y modo oscuro.
- Conservamos composición, mapa, paneles y navegación por especialidades/metodología. Ajustamos el lenguaje profesional de navegación según el encargo de ordenar la web.
- Eliminamos métricas, certificación de idioma y casos de demostración no verificados. Los casos públicos deben incorporarse con evidencia y autorización.
- El formulario original solo ejecutaba `setSent(true)`. Se sustituye por contacto directo verificable en GitHub/LinkedIn.
- Eliminamos las fichas de artículos inexistentes y los botones de CV desactivados.
- El título original era un marcador de Figma. No había metadatos SEO útiles ni páginas indexables por idioma.
- Astro genera HTML en español e inglés. Solo navegación, especialidades y metodología se hidratan con React; el contenido permanece legible sin JavaScript.

Lectura visual: evolución del boceto, variación 6, movimiento 3 y densidad 4. No se cambia a un template ni se añaden fotografías ficticias.

## Corrección de fidelidad al boceto

A petición del propietario, se restauraron las tarjetas de proyectos, el panel de fotografía pendiente y el contacto con sus enlaces, CV pendiente y formulario. El ZIP no contiene una fotografía ni un PDF de CV. Los controles pendientes se conservan visualmente; no deben eliminarse al migrar el diseño. El formulario ya no simula entrega: prepara un correo para enviarlo desde el cliente del visitante.
